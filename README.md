Leonida Ledger — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5 (1 Platinum, 2 Gold, 6 Silver, 46 Bronze). A checklist saved in the browser with export and import, filters by kind (story, missable, collectibles, activities), a spoiler setting that hides story trophies until earned, a five-stage roadmap to the platinum, the one missable trophy flagged with a save plan, and a guide in our own words for every trophy, each citing its sources (Exophase, PSNProfiles, PowerPyx, Output Lag, KeenGamer, WikiGTAVI). Static files only — no network requests, no Rockstar artwork.

## Run it

```sh
python3 -m http.server --directory app 8080
# then open http://localhost:8080 in a desktop browser
```
